# UNSAID 操作モック

海外の病院で、言葉が通じない患者と医療者の問診を支援する Web アプリの、**操作確認用モック**です。
診断や治療提案は行いません。**実際の診療には使用できません。**

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます（同じネットワークのスマートフォンからは、表示される Network の URL で開けます）。

- 型チェック：`npm run typecheck`
- 本番ビルド：`npm run build` → `npm run preview`

## 画面

- 上部の濃い色のバー（DEMO）は発表者用のデモ操作です：シナリオ選択／リセット／通信エラーの再現／手順の表示。
- PC（幅 900px 超）：左に患者画面（日本語）、右に医療者画面（English）。
- スマートフォン：タブで切り替え。相手から届くと、もう一方のタブに「新着」が付きます。
- 点線で囲まれた「デモ用サンプル」は、デモを進めるための入力補助です。

## 固定データで再現している範囲

バックエンド・認証・外部 API・録音・翻訳は**ありません**。

| 項目 | 再現方法 |
| --- | --- |
| 翻訳 | `src/data.ts` の固定サンプルのみ。画面上に「デモ用の翻訳」「Demo translation」と表示 |
| 音声認識 | 「音声入力を試す」で、録音せずにサンプルの発言を入力 |
| 意味の確認 | サンプルの発言「昨日から、たまに胸が苦しい」の「苦しい」だけを対象に確認カードを表示 |
| 通信 | 約 1 秒の待機で送信を再現。通信エラースイッチが ON なら送信失敗にする |
| データ | メモリ内だけで管理。リロード・リセットで初期状態に戻る |

用意されている文章（句読点や空白の違いは同じ文章とみなします）：

- 医療者：What brings you in today? / Have you taken any medicine for this? / Where does it hurt?
- 患者の回答：昨日から、たまに胸が苦しい / 昨日から、たまに胸が痛い / 右側です / 左側です / 真ん中です / 薬の質問への はい・いいえ・覚えていない
- 患者からの質問：もう一度説明してください / 質問が分かりません / ゆっくり話してください

これら以外の文章を入力すると「モックでは、この文章の翻訳は生成されません」と表示され、送信できません（「サンプルに戻す」で戻せます）。
送信内容は送信のたびに現在の入力から組み立て直すため、入力を変更した後に変更前の翻訳が送られることはありません。

## 状態の扱い

- 下書き → 確認中 → 送信中 → 受信済み、と失敗時の送信失敗、訂正後の訂正済みを区別して表示します。
- 送信前の入力や確認内容は、相手の画面には表示されません。
- 各メッセージは ID（例：`#M-002`）を持ち、回答はどの質問への回答かを保持します。
- 下書きの ID は作成時に決まり、送信中の連打や再送信で同じメッセージが重複しないようにしています。
- 訂正は「訂正が届いた」状態と「相手が訂正を確認した」状態を分けて管理します。

## 主なファイル

- `src/data.ts` — サンプルの会話・翻訳・シナリオ
- `src/compose.ts` — 入力から「相手に伝える内容」を組み立てる処理
- `src/state.ts` — 状態管理（reducer）とシナリオの初期状態
- `src/components/` — 患者画面・医療者画面・デモ操作バー
